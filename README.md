# 🪨 Rock Paper Scissors – React Game

A modern **Rock Paper Scissors game** built with **React + Vite**.

## 🚀 Features
- User vs Computer gameplay
- Score tracking
- Round system
- Countdown timer
- Sound effects (Win / Lose / Draw)
- Clean & responsive UI

## 🛠 Tech Stack
- React
- Vite
- JavaScript
- CSS
